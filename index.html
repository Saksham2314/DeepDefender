DeepDefender

Explainable aggression detection for Hindi-English code-mixed ("Hinglish") text, using a four-model transformer stack and a logistic-regression meta-classifier, with built-in fairness and robustness probing.

View source on GitHub → Read the full README
This page is informational only

There is no publicly hosted prediction service. Detection runs on four fine-tuned Hugging Face transformer models (~3GB of weights) served by a local FastAPI backend — it only works when you clone the repo and run that backend on your own machine (GPU recommended, CPU works but is slower). The browser extension talks to http://localhost:8000 by default, so it's equally local-only. Nothing here runs or predicts live from this page.

What it does

Most aggression/hate-speech detectors are trained on monolingual English. DeepDefender targets the much messier reality of Indian social media: Hindi written in Roman script, mixed mid-sentence with English, full of spelling variation and slang. Given a piece of text, it classifies it into one of three TRAC-1 categories and returns a confidence score and a plain-language explanation of which words drove the decision.

NAG
Non-Aggressive
CAG
Covertly Aggressive
OAG
Overtly Aggressive

Architecture

XLM-RoBERTa IndicBERT v2 mBERT HingRoBERTa
↓ independently fine-tuned, each outputs 3 class probabilities ↓
Logistic Regression meta-classifier (stacking)
↓
Label + confidence + occlusion/SHAP explanation

The baseline ensemble stacks XLM-R + IndicBERT + mBERT per the original project proposal; HingRoBERTa (pretrained specifically on Hinglish code-mixed text) was added afterward as a standalone comparison model, trained and evaluated on the identical data split.

Measured results

Trained on the deduplicated TRAC-1 Hindi-English aggression corpus (~14.5K rows, seed=42, 80/10/10 stratified split). Every number below comes from an actual run of this codebase — see docs/RESULTS_ANALYSIS.md in the repo for the full writeup and a leakage audit.

The stacking ensemble beat every individual base model on every metric and every per-class F1 score — a measured ~1-point improvement, not assumed going in.

What the probes found

Fairness probe On a hand-written template test, a non-aggressive control sentence ("I have no problem with {group} people") was classified as covertly aggressive for some identity-group substitutions and non-aggressive for others, with the sentence otherwise identical. A real, measured behavior difference — not evidence of general bias on 40 cases, but worth real scrutiny.
Robustness probe 20% of perturbed sentence variants flipped predicted label versus their base form. The model was least stable under Romanized-Hindi spelling variation and English/Hindi code-switching — the exact phenomena that make Hinglish hard in the first place — and fully stable to misspellings, capitalization, mentions, and URLs.

What's in the repo

  • Reproducible dataset prep & stratified split (src/dataset.py)
  • Configurable Hinglish preprocessing (src/preprocessing.py)
  • Per-model fine-tuning with VRAM-conscious defaults for a 4GB laptop GPU (src/model_training.py)
  • Held-out-validation stacking, documented against leakage (src/stacking.py, docs/STACKING.md)
  • Occlusion + SHAP explainability (src/explainability.py)
  • Fairness & robustness probe suites (src/fairness.py, src/robustness.py)
  • FastAPI inference server (api/main.py)
  • Chrome MV3 browser extension (extension/)
  • Streamlit research dashboard (dashboard/app.py)

Run it yourself

git clone https://github.com/Saksham2314/DeepDefender.git
cd DeepDefender
pip install torch --index-url https://download.pytorch.org/whl/cu126  # or cpu build
pip install -r requirements.txt

python -m src.train --check          # verify GPU/environment
uvicorn api.main:app --reload        # local inference API on :8000

Full setup, dataset placement, and training instructions are in the repo's README.
